# Smart Healthcare and Management with AI System

A web-based healthcare management system developed for the **CSE307 – System Analysis and Design** course project.

The system provides a centralized platform for patients, doctors, receptionists, pharmacists, laboratory technicians, and administrators to manage healthcare-related activities.

## Project Features

- User Registration and Role-Based Login
- Patient Profile Management
- Doctor Availability
- Appointment Booking and Management
- AI-Based Symptom Assessment
- Patient Medical Records
- Doctor Consultation Management
- Digital Prescription Management
- Laboratory Test Requests
- Laboratory Results and Reports
- Medicine Inventory Management
- Billing and Payment Management
- Feedback and Complaint Management
- User and Role Management
- Administrative Monitoring and Audit Logs

## System Users

The system supports the following roles:

- Patient
- Doctor
- Receptionist
- Pharmacist
- Laboratory Technician
- Administrator

## AI Symptom Assessment

The AI Symptom Assessment module provides **preliminary healthcare support and referral guidance** based on patient-provided symptoms.

It is designed as a decision-support feature and does not replace professional medical diagnosis or treatment.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage for prototype data handling
- Git and GitHub for version control

## Project Type

This project is currently a **frontend functional prototype**.

Backend services, database integration, real authentication, real payment gateway integration, and production-level AI services can be added in future development.
